## 🌊 Welcome to Erin Guo’s Website

This is my personal portfolio website – welcome! It showcases my projects, skills, and personality through an ocean-inspired, interactive experience built with a modern web tech stack. [web:1]

## ✨ Overview

A modern, interactive portfolio website built with Next.js, React, and Framer Motion. [web:1]  
It features ocean-themed animations, smooth transitions, and a unique scroll-based navigation experience. [web:1]

## 🚀 Features

- 🌊 Interactive wave transitions controlled by scroll for a dynamic browsing experience. [web:1]  
- 🌅 Animated ocean background with layered water effects for depth and movement. [web:1]  
- 🫧 Bubble cursor that follows the user with trailing bubble effects. [web:1]  
- 🛰️ Orbiting skills display with floating, animated skill tags. [web:1]  
- 📱 Responsive design that works seamlessly across desktop, tablet, and mobile. [web:1]  
- 🎞️ Smooth page and component animations powered by Framer Motion. [web:1]  
- 🧩 Modern UI components built with Shadcn/ui for a clean, accessible interface. [web:1]

## 🛠️ Tech Stack

- ⚛️ Framework: Next.js 14 with React and the App Router. [web:1]  
- 🎨 Styling: Tailwind CSS for utility-first, responsive design. [web:1]  
- 🎬 Animations: Framer Motion for page transitions and interactive motion effects. [web:1]  
- 🧱 UI Components: Shadcn/ui for reusable, accessible components. [web:1]  
- 🖼️ Icons: Lucide React for consistent, modern iconography. [web:1]  
- 📊 Charts: Recharts for data visualization. [web:1]  
- ✅ Form Handling: React Hook Form for accessible forms and validation. [web:1]
